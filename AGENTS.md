# AGENTS.md — Academic website cold-start guide

This is an academic GitHub Pages / Jekyll website, **not** a nuclear compute repository. Read `README.md`, `_config.yml`, relevant `_pages/`, `_publications/` and project-specific deployment workflows before editing. Verify real repository/build state and preserve content, credentials and deployment settings.

## Standard GPT-6 Chat continuous work
For long website-maintenance tasks, reuse the domain-neutral execution and recovery rules in [the central ordinary Chat protocol](https://github.com/T-plus7/chatgpt-codex-relay/blob/main/CHAT_CONTINUOUS_EXECUTION.md). Within a Chat response, **inspect -> edit -> build/validate when tools allow -> continue** until the requested whole-site change is checked, a genuine permission blocker occurs, or the Chat run ends. A single page update or test is not a final milestone unless the user specifically requested it. Leave evidence and a clear resume step if interrupted.

Do not apply Odyssey/PJM or nuclear matrix-element gates to website work; do not modify deployment secrets or publish without required authorization. A Chat reply cannot auto-resume after it ends.
